Chapter 2 – Variables and Data Types

Overview
This folder contains small programs focused on basic data types, variable naming rules, operators, type checking, type casting, and user input. It also includes short practice problems like adding numbers, finding remainders, averages, and squares.

Concepts Covered
- Variables and assignment
- Built-in data types (int, float, str, bool, list, tuple, set, dict, None, bytes/bytearray, complex)
- type() for checking a value’s type
- Type casting (int(), float(), str(), bool())
- input() behavior (strings by default) and converting user input to numbers
- Operator categories (arithmetic, comparison, assignment, logical, bitwise, membership, identity)
- Valid vs invalid variable names (keywords, starting with digits, special characters)

Code Highlights
- Print-based “reference” scripts that show type output for many Python data types
- A full operator demo showing results for different operator groups
- Input examples showing string concatenation vs numeric addition after casting
- Practice scripts:
  - Add two numbers
  - Compute a remainder using %
  - Check the type of user input
  - Simple comparator example (a < b)
  - Average of two numbers
  - Square of a number using exponentiation

Learning Outcome
I learned the difference between values and their types, how Python treats user input, and how to safely convert input before doing math. I also got comfortable with common operators and the basic rules for naming variables.

Notes
- Some print messages have small typos (for example repeated words). Functionally the scripts still demonstrate the concepts correctly.
- The “type of input” example shows that input() always returns a string unless it is converted.
